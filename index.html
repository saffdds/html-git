Git

Git è un sistema di controllo di versione distribuito creato da Linus Torvalds nel 2005. Permette di tracciare le modifiche al codice sorgente e di collaborare con altri sviluppatori.

Perché usare Git?

  • ✅ Tiene traccia di ogni modifica al progetto
  • ✅ Permette di tornare a versioni precedenti
  • ✅ Facilita il lavoro in team
  • ✅ È veloce e sicuro

Comandi principali di Git

git init        # Inizializza un nuovo repository
git clone URL   # Clona un repository esistente
git add .       # Aggiunge i file all'area di staging
git commit -m "Messaggio"   # Salva le modifiche con un messaggio
git status      # Mostra lo stato dei file
git log         # Visualizza la cronologia dei commit
git push        # Invia le modifiche al repository remoto
git pull        # Scarica e integra le modifiche dal remoto

Flusso di lavoro tipico

  1. Creare o clonare un repository
  2. Modificare i file
  3. Aggiungere i file con git add
  4. Salvare le modifiche con git commit
  5. Condividere il lavoro con git push

La Storia di Git

Timeline di Git

  • 2005 – Linus Torvalds crea Git per gestire lo sviluppo del kernel Linux.
  • 2008 – Nasce GitHub, che rende Git accessibile e collaborativo online.
  • 2010 – Git diventa lo standard per la maggior parte dei progetti open source.
  • 2014 – GitLab emerge come alternativa self‑hosted a GitHub.
  • 2020 – Milioni di repository attivi su GitHub e GitLab, Git domina il versionamento.
  • Oggi – Git è usato da aziende, università e sviluppatori di tutto il mondo.

Come installare Git?

Ora vediamo come installare git Sul vostro computer vediamo i tutorial:

  • Windows-Scarica l’installer ufficiale da git-scm.com
  • Linux- Usa il gestore pacchetti della tua distribuzione (es. sudo apt install git su Ubuntu)
  • MacOS-Puoi installare Git in diversi modi:
    • Con xcode-select --install (installa gli strumenti da riga di comando di Xcode)
    • Con Homebrew: brew install git
    • Scaricando il pacchetto da git-scm.com
